# Olmo conformity datasets — structure and format

## Directory structure

  candidates/     — candidate pools and probe-training (social_probe_train.jsonl, truth_probe_train.jsonl)
  immutable_facts/ — minimal_items.jsonl, minimal_items_wrong.jsonl, sample_items.jsonl
  social_conventions/ — minimal_items.jsonl, minimal_items_wrong.jsonl, sample_items.jsonl
  knowledge/      — mmlu_knowledge_items_wrong.jsonl
  math/           — gsm8k_items_wrong.jsonl, mmlu_math_items_wrong.jsonl
  reasoning/      — arc_items_wrong.jsonl
  science/        — mmlu_science_items_wrong.jsonl
  truthfulness/   — truthfulqa_items_wrong.jsonl

All dataset files are JSONL (one JSON object per line). Full contents are omitted; one example line below.
